# 功能 - 数据表对应清单

| 功能模块 | 数据表名 | 说明 |
|---------|---------|------|
| 作品管理 | `works` | 存储作品基本信息 |
| 作品章节 | `chapters` | 存储作品的章节内容 |
| 小说大纲 | `book_outlines` | 存储小说分章大纲 |
| 角色管理 | `characters` | 存储作品角色信息 |
| 分镜管理 | `storyboards` | 存储AI视频分镜结果 |
| 生成历史 | `content_history` | 存储单次生成历史记录 |
| 优化历史 | `optimization_history` | 存储内容优化修改历史 |
| 模型配置 | `model_configs` | 存储所有模型配置 |
| 流水线配置 | `pipeline_config` | 存储三阶段流水线配置 |
| 生成参数 | `generation_params` | 存储当前生成参数 |
| 定时器自动化 | `timer_automation` | 存储批量自动创作配置 |
| 应用配置 | `app_config` | 存储通用应用配置（深色模式等） |

## 数据库文件路径

`/Volumes/Seagate Exp/xm_db/ai-content-txt.db`

## 数据表关系

- `chapters.work_id` → `works.id` 外键关联
- `characters.work_id` → `works.id` 外键关联  
- `storyboards.work_id` → `works.id` 外键关联
- `book_outlines.work_id` → `works.id` 外键关联
- 采用软删除机制（`deleted_at` 时间戳），数据可恢复
