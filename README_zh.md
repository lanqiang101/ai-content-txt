# AI Content Text

[English](./README.md) | 简体中文

一款功能强大的AI小说和内容创作工具，支持多阶段生成、批量自动化、记忆管理和全面的作品管理功能。

## ✨ 功能特点

### 🎯 核心创作功能
- 🚀 **三级流水线创作**：从大纲到详细内容再到最终成品，逐步生成小说内容
- 📝 **多内容类型支持**：同时支持文章和小说创作，提供专业化参数配置
- 🎨 **灵活重新生成**：每个阶段支持单独重新生成，保留满意的结果，改进不满意的部分
- 🔄 **批量自动化**：连续自动生成多部作品，支持自定义主题和间隔时间
- ⏱️ **定时自动化**：可配置时间间隔的批量创作任务调度

### 🧠 高级记忆系统
- 💾 **向量记忆检索**：使用 Xenova/all-MiniLM-L6-v2 嵌入模型进行智能上下文检索
- 📚 **多类型记忆管理**：人物档案、情节要点、伏笔线索和章节摘要
- 🔍 **智能上下文注入**：生成前自动检索并注入相关记忆
- 🗜️ **记忆压缩**：智能去重和合并相似的记忆条目
- 📊 **优先级加权**：不同记忆类型具有不同权重（人物 > 情节 > 伏笔 > 章节）

### 📋 作品管理
- 📁 **全面的作品库**：分页和筛选管理所有创建的作品
- 📊 **实时进度跟踪**：监控所有活跃任务的生成进度
- ⏸️ **任务控制**：随时启动、暂停、恢复和取消生成任务
- 📖 **章节编辑器**：内置编辑器，查看和编辑生成的章节
- 🎬 **分镜生成**：将文本章节转换为视频分镜脚本
- 🔍 **搜索和筛选**：按标题、主题或状态搜索作品

### 🔌 模型集成
- 🤖 **双模型支持**：无缝切换本地 Ollama 模型和在线 API 模型
- 🎛️ **分阶段模型配置**：为大纲、扩展和润色阶段配置不同的模型
- 🔥 **火山引擎方舟集成**：原生支持火山引擎豆包模型
- ⚙️ **可定制参数**：温度、top_p、最大token数和超时设置

### 💻 用户体验
- ⌨️ **快捷键支持**：`⌘/Ctrl + Enter` 快速开始生成
- 📔 **历史记录管理**：自动保存所有创作历史并附带时间戳
- 🎯 **可定制配置**：全面的读者画像、角色设计、情节结构、节奏、细节、情感和反AI检测设置
- 🌐 **响应式设计**：在桌面和移动设备上无缝运行
- 🌓 **深色模式支持**：在浅色和深色主题之间切换
- 🔔 **浏览器通知**：长时间运行的任务完成时收到通知
- 🎲 **随机灵感**：一键随机生成关键词、风格和配置

## 🚀 快速开始

### 环境要求

- Node.js（推荐 18 版本以上）
- npm/yarn/pnpm 包管理器
- 后端服务器运行（用于数据库和记忆管理功能）

### 安装

```bash
# 克隆仓库
git clone https://github.com/lanqiang101/ai-content-txt.git
cd ai-content-txt

# 安装依赖
npm install
```

### 后端设置

项目包含用于数据库管理和记忆系统的后端服务器：

```bash
# 进入服务器目录
cd server

# 安装服务器依赖
npm install

# 启动后端服务器
node index.js
```

后端服务默认运行在 `http://localhost:3000`。

### 前端开发

```bash
# 在根目录启动开发服务器
npm run dev
```

打开浏览器访问 `http://localhost:5173` 即可使用应用。

### 构建

```bash
# 生产环境构建
npm run build
```

构建后的文件会输出到 `dist` 目录。

## 🎯 使用指南

### 1. 初始配置

点击右下角的设置图标进行配置：
- **模型设置**：为每个阶段设置API端点、密钥和模型名称
- **系统配置**：配置热门话题、续写设置和优化偏好
- **记忆设置**：启用/禁用向量嵌入并配置检索参数

### 2. 单篇创作

**步骤1：输入基本信息**
- 选择内容类型（文章/小说）
- 输入主题、关键词、期望字数
- 选择写作风格和语气

**步骤2：配置小说参数**（仅小说）
- **读者画像**：目标受众年龄、性别偏好、核心诉求
- **角色设计**：主角特质、缺陷、成长弧线
- **情节结构**：故事弧类型、冲突强度、节奏
- **节奏控制**：场景转换、张力曲线
- **细节程度**：描述密度、对话比例
- **情感基调**：整体情绪和情感 progression
- **反AI检测**：使文本更像人类写作的技巧

**步骤3：开始生成**
- 点击"开始创作"启动三阶段流程
- 在输出面板中监控实时进度
- 任务在后台运行 - 您可以离开页面稍后返回

**步骤4：审查和完善**
- 在阶段性面板中查看生成的内容
- 如需要可重新生成个别阶段
- 在作品详情页直接编辑章节

### 3. 批量自动化

**设置批量主题**
- 添加多个要批量生成的主题
- 为所有作品配置通用参数
- 设置要生成的作品总数

**配置自动化**
- 设置作品之间的时间间隔（例如5分钟）
- 启用/禁用自动续写
- 配置通知偏好

**启动批量流程**
- 点击"开始自动批量创作"
- 在自动化面板中监控进度
- 所有作品自动保存到作品库

### 4. 作品管理

**查看所有作品**
- 导航到"作品管理"页面
- 按状态筛选（草稿/生成中/已完成/失败）
- 按标题或主题搜索
- 大型库的分页视图

**管理任务**
- 查看所有正在运行的任务及实时进度
- 取消或暂停正在进行的生成
- 恢复中断的任务
- 查看详细统计信息（总字数、章节数等）

**编辑和续写**
- 打开任何作品查看完整内容
- 单独编辑章节
- 使用AI续写或优化特定章节
- 从文本生成视频分镜

### 5. 记忆管理

**访问记忆管理器**
- 导航到"记忆管理"页面
- 查看按类型组织的所有存储记忆

**记忆类型**
- **人物**：详细的角色档案，包括特征和关系
- **情节**：关键情节点和故事发展
- **伏笔**：埋下的线索和未来揭示
- **章节**：章节摘要和关键事件

**记忆操作**
- 按相关性搜索记忆
- 手动添加/编辑/删除记忆
- 压缩冗余条目
- 导出/导入记忆数据库

## 🏗️ 架构设计

### 前端技术栈
- **框架**：React 18 + TypeScript
- **构建工具**：Vite 5
- **状态管理**：Zustand 带 persist 中间件
- **样式**：Tailwind CSS 3
- **图标**：Lucide React
- **路由**：React Router 6
- **数据库客户端**：Better-SQLite3（通过后端API）

### 后端技术栈
- **运行时**：Node.js with Express
- **数据库**：SQLite with Better-SQLite3
- **向量嵌入**：Xenova Transformers.js
- **API**：用于作品、记忆和配置的RESTful端点

### 数据流
```
用户输入 → Store (Zustand) → 后端API → SQLite数据库
                                    ↓
                            记忆管理器 → 向量数据库
                                    ↓
                            AI模型API → 生成内容
                                    ↓
                            Store更新 → UI刷新
```

### 核心组件

**状态管理**
- `useStore`：配置、参数、生成状态、作品的中央存储
- `persist`：选择性持久化（仅配置，不包括运行时状态）
- `currentWorkId`：跟踪活跃的生成任务

**生成流水线**
- `useCycleGeneration`：带中止支持的多阶段生成逻辑
- `useModelCall`：带错误处理的模型API通信
- `usePromptBuilder`：带记忆注入的动态提示构建

**记忆系统**
- `NovelMemoryManager`：服务器端记忆编排
- `useMemory`：客户端记忆操作
- 基于类型的加权向量相似度搜索

## 🎓 高级功能

### 记忆检索策略

系统使用复杂的记忆检索策略：

1. **查询构建**：基于当前章节上下文和前文内容
2. **类型加权**：人物(1.5倍) > 情节(1.2倍) > 伏笔(1.0倍) > 章节(0.8倍)
3. **相似度阈值**：仅返回余弦相似度 > 0.7 的记忆
4. **Top-K选择**：每种类型检索最相关的5条记忆
5. **上下文注入**：将记忆格式化为自然语言提示词

### 任务管理

**后台执行：**
- 即使您离开页面，任务也会继续运行
- 通过全局store中的 `currentWorkId` 跟踪状态
- 每30秒将进度持久化到数据库
- 完成时发送浏览器通知

**多任务支持：**
- 无需等待完成即可创建多个任务
- 每个任务拥有独立的AbortController
- 在作品库中查看所有任务
- 单独的任务控制（取消/恢复）

### 提示工程

系统使用先进的提示工程技术：

- **阶段特定提示**：为大纲、扩展和润色定制的提示
- **记忆增强生成**：将相关记忆注入上下文
- **反检测模式**：减少AI生成文本模式的技巧
- **风格一致性**：跨章节保持一致的声音
- **长度控制**：每个周期的动态字数目标
