# AI Content Text

[English](./README.md) | 简体中文

一个三级流水线 AI 内容创作工具，帮助你从大纲到成品一步步生成高质量内容。

## ✨ 功能特点

- 🚀 **三级流水线创作**：从大纲到详细内容再到最终成品，逐步生成内容
- 🎨 **灵活重新生成**：每个阶段支持单独重新生成，保留满意的结果，改进不满意的部分
- 🔌 **双模型支持**：支持本地 Ollama 模型和在线 API 模型无缝切换
- ⚡ **纯前端实现**：所有配置和历史都保存在本地，无需后端服务
- ⌨️ **快捷键支持**：`⌘/Ctrl + Enter` 快速开始生成
- 📔 **历史记录管理**：自动保存所有创作历史，支持随时查看和管理
- 🎯 **自定义配置**：可以为不同阶段配置不同的模型，获得最佳效果
- 📝 **支持多种内容类型**：适用于文章和小说创作

## 🚀 快速开始

### 环境要求

- Node.js（推荐 16 版本以上）
- npm/yarn/pnpm 包管理器

### 安装

```bash
# 克隆仓库
git clone https://github.com/lanqiang101/ai-content-txt.git
cd ai-content-txt

# 安装依赖
npm install
```

### 开发

```bash
# 启动开发服务器
npm run dev
```

打开浏览器访问 `http://localhost:5173` 即可使用。

### 构建

```bash
# 生产环境构建
npm run build
```

构建后的文件会输出到 `dist` 目录。

## 🎯 使用方法

1. **配置模型**：点击右下角设置图标配置你的 AI 模型，可以为三个阶段分别设置不同的模型
   - 本地模式：配合 Ollama 使用，填写本地 Ollama 地址和模型名称
   - API 模式：配合兼容 OpenAI 的 API 使用，填写 API 地址、模型名称和 API Key

2. **输入信息**：选择内容类型（文章/小说），输入主题、关键词、期望字数和风格要求

3. **开始生成**：点击「开始生成」或使用 `⌘/Ctrl + Enter` 快捷键，应用会自动完成三个阶段的生成：
   - 第一阶段：生成内容大纲
   - 第二阶段：根据大纲扩展成详细内容
   - 第三阶段：润色优化得到最终成品

4. **按需重新生成**：如果对某个阶段的结果不满意，可以点击该阶段的重新生成按钮，单独重新生成该阶段，保留其他阶段的结果

5. **查看历史**：点击左上角历史图标，可以查看所有之前的创作记录
